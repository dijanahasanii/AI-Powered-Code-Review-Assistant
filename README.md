# AI-Powered Code Review Assistant

> Bachelor Thesis Project

An AI-powered full-stack web application that automatically analyzes GitHub repositories, detects code issues, generates reports, and can safely apply and push automated fixes back to GitHub.

---

## Features

- GitHub OAuth Authentication
- Repository Connection
- Automated Code Analysis
- AI-Generated Reports
- Real-time Dashboard (Socket.IO)
- AI Auto-Remediation
- Automatic Commit & Push
- Review History & Statistics

---
